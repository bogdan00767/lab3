# Лабораторная работа №3: Статические и динамические библиотеки в C++

## Описание проекта

Данный проект является результатом третьей лабораторной работы. Код, разработанный во второй лабораторной работе (проверка языка AsciiDoc, поиск элементов и валидация анкеты), был вынесен в отдельные библиотеки.

> **Важное примечание:** Работа выполнялась на операционной системе **macOS**. Поэтому используются Unix-аналоги библиотек:
>
> - `.a` — статическая библиотека (аналог `.lib` в Windows).
> - `.dylib` — динамическая библиотека (аналог `.dll` в Windows).

## Структура проекта

- `lib/` — исходный код библиотеки (`asciidoc`, `form`, `menu`), а также результаты её сборки (`liblab3.a` и `liblab3.dylib`).
- `static_test/` — проект-потребитель статической библиотеки. Содержит `main.cpp`, ресурсы и скомпилированную программу `app_static`.
- `dynamic_test/` — проект-потребитель динамической библиотеки. Содержит `main.cpp`, ресурсы и скомпилированную программу `app_dynamic`.

## Инструкция по сборке и запуску

Все команды выполняются из терминала. Для корректного отображения кириллицы при запуске используется локаль `LANG=ru_RU.UTF-8`.

### 1. Сборка статической библиотеки и программы

Перейдите в папку `lib`, скомпилируйте объектные файлы и упакуйте их в архив:

```bash
cd lib
g++ -Wall -Wextra -std=c++17 -c asciidoc.cpp form.cpp menu.cpp
ar rcs liblab3.a asciidoc.o form.o menu.o
```

Перейдите в `static_test` и соберите программу, прилинковав статическую библиотеку:

```bash
cd ../static_test
g++ -Wall -Wextra -std=c++17 -I../lib main.cpp -L../lib -llab3 -o app_static
```

**Флаги:**

- `-I` — заголовочные файлы.
- `-L` — путь к библиотеке.
- `-l` — имя библиотеки без приставки `lib` и расширения.

**Запуск:**

```bash
LANG=ru_RU.UTF-8 ./app_static
```

### 2. Сборка динамической библиотеки и программы

Перейдите в папку `lib` и скомпилируйте файлы с флагом `-fPIC` (Position Independent Code — обязательно для динамики):

```bash
cd ../lib
g++ -Wall -Wextra -std=c++17 -fPIC -c asciidoc.cpp form.cpp menu.cpp
g++ -shared -o liblab3.dylib asciidoc.o form.o menu.o -install_name @rpath/liblab3.dylib
```

Перейдите в `dynamic_test` и соберите программу. Обратите внимание на флаг `-Wl,-rpath`, который вшивает в программу путь для поиска `.dylib`:

```bash
cd ../dynamic_test
g++ -Wall -Wextra -std=c++17 -I../lib main.cpp -L../lib -llab3 -Wl,-rpath,@executable_path/../lib -o app_dynamic
```

**Запуск:**

```bash
LANG=ru_RU.UTF-8 ./app_dynamic
```
